# 유현재 — Personal Profile

유현재를 소개하고, 직접 관심 분야와 세부 주제를 추가해 정리하는 개인 프로필/CV형 정적 웹사이트입니다. 분야나 주제는 예시 데이터로 미리 채워두지 않았습니다.

## 주요 기능

- 자기소개와 한 줄 소개를 직접 작성하고 수정
- 관심 분야를 자유롭게 추가하고, 각 분야에 세부 주제를 계속 추가
- K 값을 2부터 5까지 선택해 각 항목에 둘 수 있는 최대 하위 항목 수 조정
- 작성 내용은 해당 브라우저의 `localStorage`에 저장
- 모바일 화면에 맞춰 트리와 소개 페이지가 재배치

## 과제 자료구조

이 사이트는 K-진 트리(K-ary tree)를 사용합니다. 루트 노드는 `유현재`이고, 관심 분야가 루트의 자식 노드가 됩니다. 각 분야와 그 하위 주제도 같은 노드 구조를 갖습니다. 사용자가 선택한 K 값은 각 노드가 가질 수 있는 최대 자식 수를 제한합니다. 기본 K는 3입니다.

트리 데이터는 각 노드에 `id`, `title`, `description`, `children`을 두는 중첩 구조로 저장합니다. 따라서 루트부터 특정 항목까지의 경로를 따라 분야와 하위 주제를 탐색할 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 저장소를 만들고 `index.html`, `style.css`, `app.js`, `README.md`를 저장소 최상위에 올립니다.
2. 사용자 사이트 주소를 원한다면 저장소 이름을 `계정이름.github.io`로 설정합니다.
3. 저장소의 **Settings → Pages**에서 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`를 선택해 저장합니다.
4. 배포 후 `https://계정이름.github.io`에서 확인합니다.

별도 설치나 빌드 과정은 필요하지 않습니다.
